# District98 — Homecoming after-movie

A 30-second after-movie of the Homecoming theatre show by dance school District98,
cut from the live recording and dressed in the District98 identity (Bart de Graaff, 2021).

Footage and renders stay out of this public repo. The source video is handed over as an
asset on a **draft** release (drafts are visible only to collaborators).
